WHICH CLAUDE
  P1 and P2 use Claude Code (the Code tab of the Claude desktop app, or
  the claude CLI), opened in the repo folder, so Claude can read SPEC.txt,
  create files, run tests and commit.
  P3 uses GOOGLE ANTIGRAVITY. The P3 file has its own setup section and an
  "ANTIGRAVITY RULES" block at the top of every prompt - keep that block
  when pasting. If P3 takes a P4 prompt, paste that same rules block first.
  If you use plain Claude chat instead, paste SPEC.txt first, then the
  prompt, and copy the files it writes by hand. Claude Code is strongly
  recommended.

HOW TO RUN ONE PROMPT
  1. git pull --rebase (Claude also does this).
  2. Start a NEW Claude Code session in the chakra/ folder.
  3. Copy the whole block between "----- COPY BELOW -----" and
     "----- END -----" and send it.
  4. Read Claude's final report. It must show real test/build output.
     If it says STOP, answer its question. Never reply "just guess".
  5. Only move on when the prompt's checks pass and it has pushed.

WHY IT SHOULD NOT BREAK
  - Every file has exactly one owner (SPEC Section 3), so three people can
    push to main at the same time without merge conflicts.
  - P2 pushes stubs for every endpoint early, so all screens can be built
    against the real API shape from the morning.
  - Every prompt lists the only files Claude may touch, the exact checks
    to run, and tells Claude to stop instead of inventing anything.
  - Python must be 3.12 (this laptop has 3.15, which has no OR-Tools or
    PyTorch packages yet). SPEC Section 4 shows how to get 3.12 with uv.

IF SOMETHING BREAKS
  - Backend will not start: run .venv\Scripts\python -m pytest -q and send
    the first error to the file's owner (SPEC Section 3).
  - A page is blank: open the browser dev tools Console, copy the first
    red error to the page's owner.
  - Wrong Python: .venv\Scripts\python --version must print 3.12.x.
  - Demo day: POST /api/demo/reset (the "Reset demo" button) restores the
    seeded state in seconds. Twin and scale results load from cache.
