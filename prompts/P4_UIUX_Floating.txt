=====================================================================
P4 PROMPTS - UI / UX: build the approved mockup into the real app
Whoever finishes their own prompts first takes the next P4 prompt.
=====================================================================
What P4 delivers
  The real React app looks like the approved mockup: the forest video
  behind every page, Instrument Serif headings with one italic accent word,
  Inter body text, the navbar with the leaf logo, frosted-glass cards, pill
  buttons, and the Home landing page.
  The visual source of truth is in the repo:
    design/mockup/README.txt      design summary and exact values
    design/mockup/*.dc.html       the six approved screens (reference markup)
    frontend/public/media/        chakra-bg.mp4 + chakra-bg-poster.jpg
  The .dc.html files are NOT React code. Read them for colours, sizes,
  spacing, radii, shadows and structure; never copy their {{holes}},
  <sc-for>, <sc-if> or class Component code, and never copy their sample
  numbers into the app.

Rules for P4 (read before claiming)
- Claim a prompt in the team chat first: "P4-2 claimed by P1". One person
  per P4 prompt at a time. Never run two P4 prompts in parallel.
- P4 owns ONLY: frontend/src/styles/*, frontend/src/ui/*,
  frontend/src/pages/Home.jsx, frontend/src/pages/Home.css,
  frontend/public/media/*. All other pages belong to P1/P2/P3. P4-7 is the
  only prompt that touches their pages, and only with the owner's "OK".
- Never change component names, props, exports or CSS variable names
  (SPEC 16.4 and 16.5). Other people's pages depend on them. Adding a new
  OPTIONAL prop or a new CSS variable is allowed.
- Never change text claims, numbers or honesty badges.
- No new npm packages: fonts via Google Fonts @import, icons as inline
  SVG, animations as CSS keyframes (SPEC 16.5).
- Every P4 prompt ends with npm run build passing and a commit whose
  message starts "P4(<your P number>):".
- Order: P4-1 -> P4-2 -> P4-3 -> P4-4 (Home) -> P4-5 -> P4-6 -> P4-7 -> P4-8.
  P4-1 to P4-3 change every page at once (shared files), so they give the
  biggest gain. P4-4 (Home) is the first thing judges see.
- P4-1 needs P3-1 pushed (the frontend skeleton). Check that
  frontend/src/ui/ and frontend/src/styles/ exist before you start.
How to use: open Claude Code in chakra/, NEW session per prompt, copy
everything between the COPY lines.
If you use Google Antigravity (P3): new agent conversation in Planning
mode, and paste the "ANTIGRAVITY RULES" block from the top of any P3
prompt BEFORE the P4 prompt text.
